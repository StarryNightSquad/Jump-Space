## 关键变量名对照

| 自然语言 | 变量名 | 说明 |
|---------|--------|------|
| 白名单 | `m_AllowedItems` | 模块可装备的武器GUID列表，非空时仅允许列表内武器 |
| 黑名单 | `m_ForbiddenItems` | 模块禁止装备的武器GUID列表，非空时禁止列表内武器 |
| 枪械注册表 | `m_WeaponEntriesByGuid` | ModuleClassifier维护的枪械武器字典，Key=TemplateGuid |
| 候选近战武器 | — | 出现在Allowed/Forbidden中但不在m_WeaponEntriesByGuid中的GUID |
| 非武器禁止项 | — | 仅在ForbiddenItems中出现的GUID，非武器（消耗品/Cosmetic等） |
| 基础模块 | `m_IsBasicModule` | UI标记字段，标记基础模块（不影响生成逻辑） |
| 分类阈值 | `forbidMostMelee` | ForbiddenItems中禁止近战数×2 > 总近战数 → 枪械专属 |
| 分类阈值 | `forbidMostRanged` | ForbiddenItems中禁止枪械数×2 > 总枪械数 → 近战专属 |

## 分类逻辑说明

- **近战专属 (MeleeOnly)**：白名单含近战GUID，或黑名单禁止全部枪械（forbidMostRanged）
- **枪械专属 (RangedOnly)**：黑名单禁止全部近战（forbidMostMelee），或白名单仅含枪械GUID
- **通用 (Universal)**：两者皆空，或同时允许近战和枪械
- **非武器禁止项**不影响分类（消耗品/Cosmetic等GUID仅在Forbidden中出现）
