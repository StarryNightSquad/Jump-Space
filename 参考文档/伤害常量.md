## 第四部分：CalculateServerDamage完整逻辑流程

**伤害倍率逻辑(v1.4.0纠正):**

```
爆发窗口内(5s) → damage *= 0.1f (应急保护, 90%减伤, 防止连锁丢失核心生命单位)
爆发窗口外 + 血量≥15% → 无倍率 (全额伤害)
爆发窗口外 + 血量<15% → damage *= 0.5f (低血量急救保护, 50%减伤)
爆发护盾激活 → damage *= 0.2f (80%减伤)
```

1. 解析静态引用 `[18DA911D0]`
2. 爆发窗口判断:
   - `timeSinceLostHealthCell = currentTime - m_ShipLostHealthCellTimeStamp`
   - if `burstWindow(5.0f) > timeSinceLostHealthCell` → 在应急保护窗口内，damage *= 0.1f (90%减伤，防止连锁丢失核心生命单位)
   - if `burstWindow <= timeSinceLostHealthCell` → 窗口外，进入倍率判断:
     - if `ShipHealth01 < 0.15f`
       → `damage *= 0.50f` (低血量急救保护, 50%减伤)
     - else (ShipHealth01 >= 阈值)
       → 无倍率 (全额伤害)
3. 爆发护盾: if `(ActiveBurstShield)` → `damage *= 0.2f` (80%减伤)
4. 免疫/上帝模式检查
5. DamageType特殊处理:
   - `DamageType==7`(Radiation) → 跳转@b47(跳过护盾)
   - `DamageType==4`(Fire) → 跳转@b47(跳过护盾)
6. 护盾处理: `ShieldUnitsManager.DealDamageToShields`
7. @b47目标: remainingDamage检查
8. 核心伤害: if `(remainingDamage>0)` → `ApplyDamageToShipCore`
9. 死亡反抗: if `(ShipHealth>0)` → `ConsumeDeathDefiance`
