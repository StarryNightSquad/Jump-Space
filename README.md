## ⚖️ 物品权重编辑

允许玩家设置不同品质物品的生成概率占比。

- 可控制 **武器与模块** 等具有稀有度的物品生成。
- 可以控制 **5 个难度** 的全局资源倍率（理论上涵盖了收集品、消耗品、物品三类）。
- Mod 改变的是 **生成权重** 而非概率，其算法为：

  > 指定品质稀有度权重 ÷ (Common 权重 + Rare 权重 + Epic 权重 + Legendary 权重)

- Mod **无法控制**：
  - 生成几率（即资源点是否生成物品、生成物品的数量）。
  - 不同类型物品的生成权重（即一个资源点是生成消耗品还是有稀有度的物品）。
  - 同一稀有度下不同物品各自的生成权重（物品各自权重写在另一个文件中）。

> ⚠️ **注意**：物品自带的词条权重与物品本身的权重是两个分开的设置项，别忘了一起修改。

> ⚠️ **特别提醒**：由于官方近期更新改动了物品生成机制，将部分稀有度权重设为 **0** 会低概率导致箱子中不生成任何物品
> 
> **建议权重设置为1：10：100：1000就够了**，包括模块权重也不要清一色卓越，否则可能出现模块不足的问题

## 🔧 物品模块编辑

可以修改当前手持的武器与组件模块，甚至凭空生成物品。

- ~~由于无法制作出 UI 互动控制，因此需要在控制台输入指令。~~  
  **经过对这个屎山的重构，现在的 Mod 支持在游戏界面左上角的 GUI 点击操作了。**

### 该 Mod 尚不完善，存在诸多问题，包括但不限于：

- ~~编辑模块时允许选择不属于该物品的模块。~~
- ~~编辑模块时缺少部分可用于该物品的模块。~~
- ~~生成物品时列表不全。~~
- ~~生成武器时会出现瞄具丢失 Bug（指退出重进游戏后武器瞄具消失）。~~
- ~~现在这个 Mod 会导致正常生成物品时游戏崩溃。~~

> 💡 **众所周知，程序能跑就不要动。**

### 当前已知限制：

- 无法调用自然生成指令，只能模拟生成，但基本符合游戏自然生成规则。
- 由于受到游戏生成物品规则限制（专业术语叫流派差异），同一件装备可以修改的词条也可能是不一样的
- 可以生成 **未完成物品** 与 **废案物品**，也可以生成 **任务物品**。
- ⚠️ **生成不该生成的物品后果自负。**
- 生成消耗品会显示为卓越品质（修了，不知道修好没）。
